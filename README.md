# Types of Data Analysis

A quick breakdown of the four stages of analytics used to move from raw data to strategic action.

| Measure | Descriptive Analysis | Diagnostic Analysis | Predictive Analysis | Prescriptive Analysis |

| Core Question | What happened? | Why did it happen? | What may happen next? | What should we do? |

| Main Focus | Summarizing past data | Identifying causes | Forecasting future outcomes | Recommending actions |

| Complexity Level | Relatively simple (★☆☆☆) | Moderately complex (★★☆☆) | Advanced (Statistical Modeling) (★★★☆) | Highly advanced (Optimization & AI) (★★★★) |

| Business Value | Provides visibility | Provides understanding | Provides foresight | Provides strategic action |
